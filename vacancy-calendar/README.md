# Календарь вакансий: сколько открытые позиции на самом деле стоят в 2027 году

**[Открыть календарь](https://olgadimitrovagit.github.io/comp-budget-lab-ru/vacancy-calendar/)**

Заявки на найм обычно подают «все с января», и бюджет найма считают так,
будто все выйдут 1 января. Так не бывает: заявку надо согласовать, вакансию
закрыть, а кандидату отработать на прежнем месте. Календарь ставит каждой
открытой позиции реалистичную дату выхода по истории найма самой компании и
отвечает на три вопроса: сколько открытые позиции на самом деле стоят в
2027 году, чей выход сдвинуть, чтобы уложиться в лимит ФОТ, и что переходит
на 2028 год.

## Ничего скачивать не нужно

Откройте ссылку — календарь работает в браузере. Загрузите свои CSV, и цифры
посчитаются прямо во вкладке: ничего не отправляется и не сохраняется,
страница не делает ни одного сетевого запроса.

## Демо-данные

Вымышленная компания: ФОТ текущего состава на 2027 год 6 000 млн ₽,
240 открытых позиций, лимит ФОТ на 2027 год 6 340 млн ₽. ФОТ и лимит — с
премией и страховыми взносами работодателя.

| ФОТ 2027 года | млн ₽ |
|---|---|
| По заявкам, каждая позиция с заявленного месяца | 6 779,03 |
| Реалистично: сроки найма, незакрытые вакансии, пустые места ушедших | 6 453,11 |
| После сдвига выхода 124 позиций | 6 339,85 |
| Лимит | 6 340,00 |

Из перерасхода 439,03 млн сроки найма снимают около 170 млн, незакрытые
вакансии и пустые места ушедших — ещё 155,89 млн; оставшиеся 113,11 млн
закрывают сдвиги. В 2028 году нанятые в 2027-м стоят 764,31 млн, на
324,46 млн больше, чем в 2027-м: сдвиги экономят только в 2027 году.

## Метод

1. Полная годовая стоимость позиции: оклад × (1 + целевая премия) +
   страховые взносы по НК РФ: 30% до предельной базы 2 979 000 ₽ и 15,1%
   сверх неё. База копится нарастающим итогом с месяца выхода, поэтому
   поздно вышедший может до неё не дойти. Доля ставки (`fte`) умножает
   оплату и взносы линейно: 0,5 стоит ровно половину полной ставки.
2. Дата выхода: заявленный месяц, но не раньше, чем успеют согласовать
   заявку и закрыть вакансию, считая от 1 января. Сроки согласования и
   поиска — медианы по грейду из истории найма; грейд, где закрыто меньше
   3 вакансий, берёт сроки по умолчанию. Кандидат, который уже в воронке,
   выходит через заданное число дней от даты плана (собеседование 40,
   оффер 20) или в согласованную дату. Проектная позиция выходит не раньше
   запуска проекта. Выход после 15-го числа в бюджете считается со
   следующего месяца.
3. Реалистичный прогноз: позиции без кандидата считаются с долей закрытия
   (по умолчанию 90%); места ушедших какое-то время пустуют (по умолчанию
   10% в год, 2 месяца), и это вычитается из текущего ФОТ.
4. Сдвиги: только позиции без кандидата, не проектные и не помеченные как
   критичные. Сначала самые дорогие в месяц, каждая на наименьшее число
   целых месяцев, которое закрывает остаток разрыва, не больше 3 и не за
   пределы 2027 года. Взносы на укороченный год пересчитываются заново. Если
   всех возможных сдвигов не хватает, страница так и говорит и правила не
   подгоняет.
5. 2028 год: полная годовая стоимость всех, кто выходит в 2027-м, с той же
   долей закрытия и окладами 2027 года.

Все правила перечислены на странице в блоке «Ваши данные, Excel-модель и
метод»; [method.html](method.html) проходит каждый шаг с цифрами.

## Формат входных данных

Открытые позиции:

```
position_id,department,grade,base_salary,target_bonus_pct,requested_month,stage,expected_start,project_start,critical,fte
```

История найма:

```
requisition,grade,department,requested,opened,started,request_to_open_days,open_to_start_days
```

`base_salary` — годовой оклад до удержания НДФЛ, ₽. `target_bonus_pct` —
процент от оклада. `requested_month` — `ГГГГ-ММ`, даты — `ГГГГ-ММ-ДД`.
`stage` пустой, `собеседование`, `оффер` или `принят`; `expected_start` —
согласованная дата для `принят`. `project_start` заполняется только у
проектных позиций. `critical` — `да` или `нет`. `fte` необязателен: доля
ставки, пусто — 1. Первая строка истории `sep=,` необязательна.

## Как воспроизвести цифры

```
cd page && npm install && npm run build   # writes ../index.html; fails on any external load
node check-engine.mjs                      # page engine against the Python reference
node check-network.mjs                     # needs Chrome; set CHROME=<path to chrome> on macOS or Linux
cd ../build
python make_demo.py                        # writes ../sample-positions.csv
python build_model.py                      # writes ../vacancy-calendar-model.xlsx (needs openpyxl)
powershell -File recalc.ps1                # recalculates it in Excel
python check_model.py                      # 1,611 figures against reference_calc.py
python build_method.py                     # writes ../method.html
```

Книга в репозитории уже пересчитана, поэтому `python check_model.py`
проверяет её как есть. Книга, заново собранная `build_model.py`, содержит
формулы без значений, пока её не пересчитает Excel. Каждая проверка
завершается с ошибкой при расхождении.

## Ограничения

Демо-данные получены генератором с фиксированным seed, реальной компании за
ними нет. Инструмент показывает метод; это не юридическая и не финансовая
консультация.

Страховые взносы — по НК РФ (п. 3 ст. 425), предельная база 2026 года
(постановление Правительства РФ от 31.10.2025 № 1705), для 2027 года взяты
ставки 2026-го; ставки и базу можно поменять. Взносы на травматизм и
пониженные тарифы не учтены. 2028 год считается по окладам 2027-го, без
индексации. Текучесть, месяцы пустого места и доля закрытия — условные
значения по умолчанию; выбытие считается по всему текущему ФОТ, без
разбивки по подразделениям. Если сдвигов не хватает, инструмент показывает,
сколько не хватает; какие позиции снять — решение руководителей.
