# План-факт ФОТ

**[Открыть дашборд](https://olgadimitrovagit.github.io/comp-budget-lab-ru/budget-plan-fact/)**

Дашборд сигнальный. HR-директор открывает ссылку с телефона и за несколько
секунд видит один из двух исходов: бюджет исполняется в пределах порога или есть
проблема и пора звонить.

Дашборд отвечает, где бюджет расходится с планом и на сколько. Почему — не
отвечает: причины выясняют в разговоре.

## Ничего скачивать не нужно

Откройте ссылку — дашборд работает в браузере. Загрузите свой CSV, и цифры
посчитаются прямо во вкладке: ничего не отправляется и не сохраняется, страница
не делает ни одного сетевого запроса. Затем она отдаёт тот же самодостаточный
файл уже с вашими данными — его можно переслать дальше.

Если удобнее таблица или нужна копия:

| | |
|---|---|
| **[budget-plan-fact-model.xlsx](budget-plan-fact-model.xlsx)** | тот же расчёт в Excel, живые формулы. Скачайте и откройте: больше ничего не нужно. |
| **[sample.csv](sample.csv)** | формат входных данных, заполненный примером. Замените строки своими. |

Всё в папке `build/` — исходники, из которых собирается страница, генератор
демо-данных и проверки цифр. Это лежит здесь, чтобы расчёт можно было проверить.
**Чтобы пользоваться дашбордом или моделью, ничего из этого не нужно.**

## Что такое ФОТ здесь

План и факт — фонд оплаты труда: оклады и переменная часть, **без страховых
взносов работодателя**, как принято в российской практике. Если ваш бюджет
ведётся вместе со взносами, загрузите суммы со взносами: дашборд и модель
считают отклонения от того, что в файле.

## Откуда прогноз

Прогноз на сентябрь–декабрь продолжает тренд каждого подразделения: план
месяца, умноженный на (1 + отклонение подразделения от плана за январь–август).
Прогноз «ровно по плану» молча предполагал бы, что перерасход с сентября
исчезнет.

## Формат входных данных

CSV с колонками:

```
department,month,month_no,plan,fact,forecast
Продажи,янв,1,1200000,1176000,
Продажи,сен,9,1200000,,1200000
```

`fact` заполнен по последний закрытый месяц и пуст после него; `forecast` —
наоборот. У каждого подразделения должны быть все двенадцать месяцев. Месяцы —
краткие русские названия (`янв` … `дек`), порядок задаёт `month_no`. Суммы в
рублях. `sample.csv` — рабочий пример на два подразделения.

Комментарий для директора вводится на странице, в CSV его нет.

## Excel-модель

`budget-plan-fact-model.xlsx` повторяет расчёт живыми формулами на семи листах:
план → факт → отклонение → накопительный итог → прогноз по тренду → итог года.
Ни одна величина, которую можно посчитать, не вписана числом: openpyxl пишет
формулы, считает их настоящий Excel. Жёлтое — исходные данные, голубое —
формулы, зелёное — настройки (число месяцев с фактом, порог сигнала). Тренд
подразделений — на листе «Тренд»: поменяйте его, и прогноз с итогами
пересчитаются.

Книга пересчитана живым Excel и сходится с CSV до 0,00 ₽ по пяти контрольным
цифрам: план года, ожидание на год, отклонение за год, план и факт за восемь
месяцев. Ошибок формул нет.

```

budget-plan-fact-model.xlsx         the same model in Excel, live formulas
sample.csv                          two-department example of the input format
README.md                           this file

build/                              sources and checks - not needed to use the tool
  template.html                     markup and page logic (calculation, CSV, threshold)
  build_dashboard.py                checks the data and embeds it into the page
  lovable/                          styles and chart, inlined into the page at build
    styles.css                      Tailwind 4 stylesheet: palette, both themes, components
    chart.jsx                       the monthly chart (React + Recharts)
    build.py                        compiles both, inlines them, calls build_dashboard.py
    package.json, package-lock.json the pinned toolchain (npm ci)
    vite.config.js, entry.js        bundle settings
  generate_dataset.py               the seeded dataset generator, with its checks
  budget-plan-fact.csv              the demo dataset, 7 departments x 12 months
  department-deviation.csv          per-department trend, input to the generator and the model
  make_sample.py                    writes sample.csv
  build_model.py                    builds the Excel workbook from the CSV
  recalc_model.ps1                  recalculates the workbook and checks it against the CSV
  comment.txt                       the comment baked into the published build
  check-network.js                  no network request on load or after a CSV is picked
```

Дашборд собирается скриптом. Правки — в `build/template.html` или `build/lovable/`, затем
`python build/lovable/build.py`: он пишет `index.html`, который и публикуется.
React и Recharts встроены в страницу, поэтому из сети она ничего не грузит.

## Как воспроизвести цифры

```
python build/generate_dataset.py          # writes budget-plan-fact.csv, runs 8 checks
python build/build_model.py               # writes budget-plan-fact-model.xlsx
powershell -File build/recalc_model.ps1   # recalculates it and verifies against the CSV
cd build/lovable && npm ci && cd ../..    # once: Node 20+, installs the toolchain
python build/lovable/build.py             # writes index.html
node build/check-network.js               # fails on any request, on load or after upload
```

Генератор детерминирован (фиксированный seed) и воспроизводит тот же CSV байт в
байт. Генератор берёт ФОТ сотрудников из демо-данных калькулятора выравнивания
оплаты (`../pay-gap-calculator/build/excel/demo-data.csv`), поэтому обе папки
нужны вместе. При расхождении проверки в каждом скрипте завершаются с ошибкой.

`check-network.js` нужны `puppeteer-core` и локальный Chrome; путь к Chrome,
если он не стандартный для Windows, задаётся переменной `CHROME_PATH`. Проверка выбирает
`sample.csv` через поле загрузки на странице, так что запрос, вызванный первой
загрузкой файла, тоже валит проверку.

## Ограничения

Данные смоделированы генератором, реальной компании за ними нет. Дашборд
показывает метод; это не финансовая и не бухгалтерская консультация.

Сознательно вне рамок: объяснение отклонений, планирование численности,
несколько валют, страховые взносы и любое сравнение подразделений, кроме размера
отклонения.
