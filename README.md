# Comp Budget Lab: инструменты для C&B

**[Открыть оглавление](https://olgadimitrovagit.github.io/comp-budget-lab-ru/)**

Три инструмента для компенсаций и бюджета ФОТ. Каждый работает в браузере по
ссылке и не отправляет ваши данные: свой CSV считается прямо во вкладке. К
каждому есть Excel-модель с живыми формулами, которая считает то же самое.

| Инструмент | Открыть | Excel |
|---|---|---|
| Пересмотр зарплат: бюджет и результат (матрица мерита) | [калькулятор](https://olgadimitrovagit.github.io/comp-budget-lab-ru/merit-matrix-calculator/) | [merit-model.xlsx](merit-matrix-calculator/merit-model.xlsx) |
| План-факт ФОТ | [дашборд](https://olgadimitrovagit.github.io/comp-budget-lab-ru/budget-plan-fact/) | [budget-plan-fact-model.xlsx](budget-plan-fact/budget-plan-fact-model.xlsx) |
| Стоимость выравнивания оплаты | [калькулятор](https://olgadimitrovagit.github.io/comp-budget-lab-ru/pay-gap-calculator/) | [pay-gap-model.xlsx](pay-gap-calculator/pay-gap-model.xlsx) |

Как устроен расчёт, формат входных данных и как воспроизвести цифры — в
README каждой папки.

ФОТ во всех трёх инструментах — оклады и переменная часть без страховых
взносов. Калькуляторы выравнивания и мерита показывают взносы отдельной
строкой: тарифы по НК РФ, предельная база 2026 года, на странице их можно
поменять. План-факт
сравнивает суммы в том виде, в каком их загрузили.

Демо-данные смоделированы генератором: 212 сотрудников вымышленной компании,
общие для всех инструментов. Это не юридическая и не финансовая консультация.
