# Comp Budget Lab: инструменты для C&B

**[Открыть оглавление](https://olgadimitrovagit.github.io/comp-budget-lab-ru/)**

Три инструмента для компенсаций и бюджета ФОТ. Каждый работает в браузере по
ссылке и не отправляет ваши данные: свой CSV считается прямо во вкладке. К
каждому есть Excel-модель с живыми формулами, которая считает то же самое.

| Инструмент | Открыть | Excel |
|---|---|---|
| Пересмотр зарплат: бюджет и результат (матрица повышений) | [калькулятор](https://olgadimitrovagit.github.io/comp-budget-lab-ru/merit-matrix-calculator/) | [merit-model.xlsx](merit-matrix-calculator/merit-model.xlsx) |
| План-факт ФОТ | [дашборд](https://olgadimitrovagit.github.io/comp-budget-lab-ru/budget-plan-fact/) | [budget-plan-fact-model.xlsx](budget-plan-fact/budget-plan-fact-model.xlsx) |
| Календарь вакансий: сколько открытые позиции стоят в 2027 году | [календарь](https://olgadimitrovagit.github.io/comp-budget-lab-ru/vacancy-calendar/) | [vacancy-calendar-model.xlsx](vacancy-calendar/vacancy-calendar-model.xlsx) |

Как устроен расчёт, формат входных данных и как воспроизвести цифры — в
README каждой папки.

Калькулятор пересмотра считает ФОТ отдельно от страховых взносов и показывает
взносы отдельной строкой: тарифы по НК РФ, предельная база 2026 года, на
странице их можно поменять. План-факт берёт ФОТ одной итоговой суммой и
сравнивает суммы в том виде, в каком их загрузили. Календарь вакансий
считает взносы по тем же тарифам, а предельную базу — нарастающим итогом с
месяца выхода.

Демо-данные смоделированы генератором. У пересмотра зарплат и план-факта
общая вымышленная компания на 212 сотрудников (`demo-company/employees.csv`);
у календаря вакансий своя, крупнее: 240 открытых позиций при ФОТ 6 млрд ₽. Это не юридическая и не финансовая консультация.
