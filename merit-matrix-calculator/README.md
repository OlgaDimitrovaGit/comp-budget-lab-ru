# Пересмотр зарплат: бюджет и результат

**[Открыть калькулятор](https://olgadimitrovagit.github.io/comp-budget-lab-ru/merit-matrix-calculator/)**

Калькулятор матрицы повышений и стоимости пересмотра зарплат. Считает повышение
каждому сотруднику и отвечает на три вопроса: кому сколько, во что пересмотр
обойдётся в этом году и в бюджете следующего, уложится ли повышение в целевой
процент. Заодно показывает, где окажутся оклады в вилках после пересмотра.

## Ничего скачивать не нужно

Откройте ссылку — калькулятор работает в браузере. Загрузите свои CSV, и цифры
посчитаются прямо во вкладке: ничего не отправляется и не сохраняется, страница
не делает ни одного сетевого запроса.

Если удобнее таблица:

| | |
|---|---|
| **[merit-model.xlsx](merit-model.xlsx)** | тот же расчёт в Excel, живые формулы, строка на сотрудника. В книге — демо-данные и параметры по умолчанию. Чтобы посчитать своих сотрудников, вставьте их на лист «Сотрудники», а вилки — на лист «Вилки», в колонках как в образцах CSV: формулы рассчитаны на 2 000 сотрудников и 500 строк вилок. |
| **[sample-employees.csv](sample-employees.csv)**, **[sample-salary-ranges.csv](sample-salary-ranges.csv)** | формат входных данных, заполненный примером: сотрудники и вилки. Те же два файла можно скачать на странице. |

## Что такое ФОТ здесь

ФОТ — оклады и переменная часть, **без страховых взносов работодателя**, как
принято в российской практике. Стоимость повышения считается полной: прибавка
к окладу, рост переменной части, которая считается в процентах от оклада, и
взносы на всё это. Поэтому там, где речь о полной стоимости, на странице
написано «ФОТ со взносами».

## Демо-данные

212 смоделированных сотрудников в семи подразделениях — та же компания, что в
[план-факте бюджета ФОТ](https://olgadimitrovagit.github.io/comp-budget-lab-ru/budget-plan-fact/).
35 вилок по подразделениям и грейдам. Пересмотр с 1 апреля 2027 года, целевой
бюджет повышения — 4% от окладов участников.

ФОТ до пересмотра — 519 834 430 ₽, со взносами — 670 750 447 ₽. В план-факте
годовой ФОТ той же компании — 521 149 442 ₽: там оплата фактическая, за
отработанные месяцы, а здесь оклады годовые, и 14 недавно нанятым оклад
поставлен ниже минимума вилки.

| | За полный год, ₽ | 2027, апрель–декабрь, ₽ |
|---|---|---|
| Прибавка к окладам | 30 279 767 | |
| Рост переменной части | 4 100 622 | |
| Страховые взносы | 7 388 440 | |
| **Стоимость повышения** | **41 768 829** (6,23% ФОТ со взносами) | **31 326 622** (4,67%) |

Фактическое повышение — 6,53% окладов участников при цели 4%: на 2,53 п.п. и на
16 406 498 ₽ в год выше целевого бюджета (в 2027 году — 12 304 874 ₽).

В пересмотре участвуют 209 человек из 212: трое не проходят по стажу или по
недавнему изменению оклада. Ниже 90% середины вилки до пересмотра — 39
человек, после — один. Трое на максимуме вилки и выше повышения не получают;
один остаётся ниже минимума вилки.

## Метод

1. **Кто участвует.** Стаж на дату пересмотра не меньше заданного (по
   умолчанию 6 месяцев) и не меньше заданного срока с последнего изменения
   оклада (по умолчанию 3 месяца).
2. **Повышение.** Целевой оклад = середина вилки × политика оплаты × целевой CR
   рейтинга. Участник ниже целевого оклада поднимается до него, затем
   ограничения в таком порядке: не меньше минимального повышения для рейтинга, не
   больше потолка повышения на человека, не выше максимума вилки, если это
   ограничение включено. На максимуме вилки и выше — без повышения. Повышения
   не подгоняются под целевой процент: вместо этого показано расхождение с
   целью.
3. **Стоимость.** Прибавка к окладу, рост переменной части и взносы. Взносы —
   по единому тарифу: 30% до предельной базы 2 979 000 ₽ в год и 15,1% сверх
   неё. Тарифы заданы п. 3 ст. 425 НК РФ, база — на 2026 год (постановление
   Правительства РФ от 31.10.2025 № 1705); база на 2027 год ещё не
   утверждена, на странице её и ставки можно поменять. Взносы на травматизм не
   включены. Этот год считается с месяца пересмотра; следующий — тот же
   пересмотр за двенадцать месяцев, без нового цикла.
4. **Цель.** Целевой бюджет — целевой процент от оклада каждого участника,
   с переменной частью и взносами, посчитанными так же.

Полностью правила изложены на странице, в разделе «Свои данные, Excel-модель,
взносы и метод».

## Формат входных данных

Сотрудники:

```
id,category,grade,rating,hire_date,last_change_date,base_salary,bonus_pct,fte
E001,Разработка,8,4,2021-08-25,2026-09-05,2279487.07,14.33,1
```

Вилки:

```
category,grade,min,mid,max
Поддержка клиентов,3,1027000,1181000,1335000
```

`category` — подразделение, `base_salary` — годовой оклад в рублях до вычета
НДФЛ при полной ставке, `bonus_pct` — переменная часть в процентах от оклада,
`rating` — от 1 до 5, `fte` — доля ставки, даты — `ГГГГ-ММ-ДД`. Без колонки
`category` (в обоих файлах) вилки подбираются только по грейду, а все
сотрудники считаются одной группой.

## Excel-модель

`merit-model.xlsx` повторяет расчёт живыми формулами: «Итоги», «Настройки»,
«Вилки», «Сотрудники», «Расчёт» (строка на сотрудника), «Матрица». Ни одна
величина, которую можно посчитать, не вписана числом: openpyxl пишет формулы,
считает их настоящий Excel. Жёлтые ячейки — ввод: параметры пересмотра на
листе «Настройки», данные на листах «Сотрудники» и «Вилки».

Книга пересчитана живым Excel и сходится с эталонным расчётом
(`build/reference_calc.py`) до 0,00 ₽ по 17 итоговым цифрам и по каждой из 212
строк сотрудников. Ошибок формул нет.

## Файлы

```
index.html                  the calculator, self-contained, no network requests
merit-model.xlsx            the same calculation in Excel, live formulas
sample-employees.csv        212 simulated employees: the input format, filled in
sample-salary-ranges.csv    their salary ranges
README.md                   this file

build/                      the model and the reference calculation
  reference_calc.py         the calculation in Python, the reference everything is checked against
  build_model.py            builds merit-model.xlsx from the sample CSV files
  recalc_model.ps1          recalculates the workbook in Excel, then runs check_model.py
  check_model.py            checks the recalculated workbook against reference_calc.py
  dump_reference.py         runs reference_calc.py on scenarios, for the page checks
  make_demo.js              writes the sample CSV files (reads ../../demo-company/employees.csv)

page/                       sources of index.html (React, Vite)
  src/engine.js             the page's calculation, a line-by-line port of reference_calc.py
  check-engine.mjs          engine against reference_calc.py, 5 scenarios
  check-page.py             the built page in a real browser: clicks, file inputs, no network requests
```

## Как воспроизвести цифры

```
cd build
node make_demo.js                          # writes ../sample-*.csv
python build_model.py                      # writes ../merit-model.xlsx (formulas only)
powershell -File recalc_model.ps1          # recalculates it in Excel and checks every row
cd ../page
npm install && npm run build               # writes ../index.html; fails on any external load
npm run check                              # page engine against the Python reference
python check-page.py                       # needs Playwright
```

Генератор демо-данных детерминирован (фиксированный seed) и берёт сотрудников
из общей демо-компании (`../demo-company/employees.csv`), поэтому эта папка
нужна вместе с ним. При
расхождении каждая проверка завершается с ошибкой.

## Ограничения

Данные и вилки смоделированы генератором: за ними нет ни реальной компании, ни
обзора рынка. Вилки считаются актуальными. Калькулятор показывает метод; это не
юридическая и не финансовая консультация.
